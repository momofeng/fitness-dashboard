# 增肌日誌（離線健身 PWA）

給增肌新手用的訓練、飲食、身體數據紀錄 App。可以加到 Android 手機主畫面，離線也能用；**紀錄預設存在你自己的裝置**（瀏覽器 IndexedDB）。可選擇免帳號加密雲端同步，資料在裝置加密後才上傳；只有你自己啟用「AI 辨識」後，辨識用的照片或文字才會送到 Google Gemini，進度照永遠不上傳。

- 使用：<https://momofeng.github.io/fitness-dashboard/>（用 Android Chrome 開啟 → 選單「加到主畫面」）
- 跨裝置可到「設定 → 加密雲端同步」建立空間，保存恢復金鑰；新裝置輸入金鑰或掃舊裝置的限時 QR 碼加入。進度照不會同步。詳見 [加密同步說明](docs/encrypted-sync.md)。
- 換手機前請到「更多 → 資料與備份」匯出備份檔，新手機在首次設定頁選「從備份檔還原」；有拍進度照的話請用「完整備份（ZIP）」

## 加密同步（v0.5）

- 不用註冊帳號，以隨機恢復金鑰解密及授權自己的裝置；配對 QR 碼限用一次、5 分鐘到期。
- 離線先存本機，連線後合併不同筆紀錄；同筆修改衝突由使用者選擇，不以時間強制覆蓋。
- 已完成訓練、飲食、身體、課表及打卡等可同步；進行中的訓練、照片、API 金鑰及裝置偏好保留本機。
- 最近 10 次成功寫入可還原，另保留 JSON／ZIP 備份；金鑰不進教練摘要或一般備份。
- 同步前確認格式與父子關聯，跨分頁互斥；清除與檔案還原會先停止並等待同步，防止資料復活。
- 雲端服務放在獨立的 Sites／Cloudflare Worker（D1 中繼資料、R2 加密內容）。v0.5.0 於 2026-10-27 發布；原網址由 GitHub Pages 自動部署，免帳號同步服務另行部署。

## 訓練紀錄改版（v0.4）

- 目前動作展開，其餘收合；逐組預填、大按鈕加減、一鍵完成並休息，確認過的草稿離線保存。
- 每組可選吃力、姿勢不穩、有人協助、不適／部位與短備註，完成後可補記；未註記不代表姿勢良好。
- 器械設定保存當次快照，kg／lb 面板、重量定義與級距可個別設定；不同機台可建立獨立版本。
- 完成頁、歷史頁、有氧頁可預覽當日多場訓練＋有氧摘要，勾選內容後複製文字或用 Android 分享圖片；不會自動傳給教練。
- 歷史更正更新統計與分享，不倒推下次重量；需注意組不列入力量 PR，該動作暫停自動調整。
- JSON／ZIP 升至 v4，保留 v1–v3 還原相容性。分享圖片是摘要，不是完整備份。
- 使用方式、摘要範例與 Android 實機驗收：[訓練紀錄說明](docs/training-log.md)。

## 功能
- **訓練**：新手全身課表等 4 套範本、訓練中模式（預填目標重量、一鍵完成並休息倒數、暖身組、槓片配重、遞減組）、線性／雙重進步自動加重、停滯提醒、PR 與 1RM 趨勢、每肌群每週組數、有氧紀錄、125 個動作的動作庫；EZ 槓與磅制槓片示意、可調的暖身比例與停滯門檻、每個動作可覆寫次數區間
- **飲食**：依 Mifflin-St Jeor 估算熱量與增肌目標、內建衛福部食物資料庫（2,160 筆原型食物）、自建食物、餐點組合、快速加入熱量、複製前一天、喝水、每週摘要、自適應 TDEE（用 21 天的實際攝取與體重變化反推，只建議不自動改）、條碼掃描（Android Chrome；只對應自建食物，不連外部資料庫）、**AI 辨識**（選用：拍照或一句話輸入 → 認出食物名稱與估計重量 → 對應內建食物資料庫 → 依重量換算營養；營養數字一律來自資料庫，不由 AI 產生；需自備 Gemini 金鑰，金鑰只存在手機、不進備份；記得你的校正，越用越準）
- **身體**：體重 7 日均線與週增重率（含速度判讀）、體脂與 FFMI、圍度、進度照（只存在手機、兩張並排比較）
- **恢復**：每天記錄睡眠、精力、痠痛部位；動作停滯又恢復不足時建議減量週，一鍵套用（組數與重量下降、不影響進步紀錄）
- **目標與習慣**：體重、動作、體脂、圍度與自訂目標自動算進度；手動或自動判定的習慣打卡；月曆熱圖
- **選品**：14 張補給品知識卡（證據等級 A–D，每條說法附 ISSN／IOC／PMID／DOI 或政府來源，不提品牌）；我的補給品的每克蛋白質成本、CP 值比較、庫存與補貨提醒、每日打卡；裝備每次訓練成本
- **其他**：首頁總覽（含今天狀態與今日打卡）、小工具（1RM、槓片、暖身組、TDEE）、JSON 備份還原（不含照片）、ZIP 完整備份（含進度照）、CSV 匯出

所有數字都是公式估算，不是醫療或營養建議。

## 開發
```bash
npm install
npm run dev        # http://localhost:5173/fitness-dashboard/
npm run verify     # typecheck + 單元測試 + build
npm run e2e        # Playwright（Pixel 7 模擬，含離線）
```
測試需 Node.js 24 以上。Playwright 會自動啟動僅限本機的同步測試服務（8789），不需要雲端帳號，也不會傳真實資料。

技術：Vite、React、TypeScript、Tailwind CSS、Dexie（IndexedDB）、vite-plugin-pwa、Recharts、Zod、fflate（ZIP）。

更新食物資料庫：從[政府資料開放平臺資料集 8543](https://data.gov.tw/dataset/8543)下載 JSON zip 放到 `data-raw/tfda-20-json.zip`，執行 `node scripts/tfda/convert.ts --version "YYYY-MM-DD 版"`。轉換會檢查單位、缺值、熱量一致性（修正熱量）與成分加總，不通過就不寫檔。

## 資料來源與授權
食物營養資料：衛生福利部食品藥物管理署「食品營養成分資料庫」（政府資料開放平臺資料集 8543），依[政府資料開放授權條款－第1版](https://data.gov.tw/license)釋出，本專案依該條款進行利用。

補給品知識卡整理自國際運動營養學會（ISSN）立場聲明、國際奧會（IOC）共識聲明、PubMed 收錄的系統性回顧與試驗、衛福部食藥署與國健署資料，來源逐條列在 App 內；僅供一般衛教參考，不是醫療建議。
