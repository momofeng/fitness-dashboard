# 訓練紀錄 v0.4

## 運動時怎麼用

1. 到訓練頁開啟固定課表。畫面只展開目前動作，點其他動作名稱可自由換順序。
2. 第一次先填實際重量；之後沿用目標／前組重量。按「完成這組」即存檔並開始休息。
3. 感覺需要讓教練知道時，開啟「狀態與備註」，或完成後按「編輯／補記」。未填表示未註記。
4. 器械設定可記住座椅、握把、提醒、面板單位及每格重量。不同機台請在動作選項另建版本，避免把不同機器的數字拿來比較。
5. 沒時間或器械被占用，可從選項跳過剩餘組並選原因；換動作會保留已做的組。
6. 有氧只要選類型和分鐘，距離、速度、坡度、阻力、感受皆選填。

## 分享與資料保存

- 完成頁、歷史頁和有氧頁都有「分享當日紀錄」。預設含該日期所有已完成場次及有氧。
- 可勾選要分享的項目與狀態、器械設定、備註，再複製文字或分享 PNG 圖片。
- 長圖片自動分頁；取消分享不會刪紀錄，也不會自動下載。無法分享時可下載，圖片多張時下載 ZIP。
- 教練摘要在自己的裝置整理，只有本人選擇分享才送出；加密雲端同步是另一個選用功能。清除瀏覽器、無痕模式、換手機都可能影響本機資料；請使用資料頁的 JSON 或完整 ZIP 備份。
- 更正歷史會更新統計與分享，不倒推重寫下次重量；請使用「手動確認下次重量」。

## Android 實機驗收

電腦上的手機模擬已覆蓋離線、重新整理、360–412px、數值逐字修改、快速重複點擊、寫入失敗、摘要多場與分頁、取消分享。下列項目仍需在實際 Android 手機確認：

- 在 Chrome 網頁及加到主畫面後，手汗、單手操作與鍵盤彈出時的觸控手感。
- 切換到其他 App／鎖定後回來的休息倒數與聲音／震動。
- Android 分享選單中的 LINE 能接收單張及多張 PNG，並由本人選擇收件人。
- 實際傳送後的中文字、圖片清晰度，以及儲存下載 ZIP 的位置。

此訓練改版隨 v0.5.0 發布到原網址；Android 實機驗收項目仍需由使用者確認。
