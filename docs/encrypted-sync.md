# 加密同步 v0.5

## 使用方式

1. 在已有紀錄的 Android 裝置開「設定 → 加密雲端同步」，按「建立同步空間」。
2. 將恢復金鑰存進自己的密碼管理工具，勾選已保存。它等同整個同步空間的存取權，請勿放進教練摘要。
3. 新手機／電腦開原本網址，於首次設定頁點「已有紀錄？使用恢復金鑰或掃碼同步」。
4. 輸入恢復金鑰，或讓舊裝置產生限時 QR 碼，新裝置從 App 內掃描。配對碼 5 分鐘到期、限用一次。
5. 先預覽資料筆數，再加入。已有本機資料時先自動下載安全備份，不同筆合併，同筆衝突由本人選擇。
6. 日常直接記錄，前景連線時自動同步。畫面會顯示待同步、離線、已同步、需要確認或錯誤；也能按立即同步。

建立空間需要先完成基本設定。新裝置加入不需要先重新填一份個人資料。

## 同步範圍與限制

- 包含已完成訓練、逐組狀態與當次器械設定、有氧、課表與進步狀態、飲食、身體數據、補給品、習慣等結構化紀錄。
- 進行中的訓練與草稿留在原裝置，完成後才同步。無法同時在另一台續做同一場訓練。
- 進度照原圖及縮圖、AI API 金鑰、相機照片、主題、音效等裝置偏好不會同步；有進度照時仍需 ZIP 完整備份。
- 分享摘要與一般 JSON／ZIP 備份均不含同步恢復金鑰。清除本機資料會停止該裝置同步，不刪雲端。
- 「停止此裝置同步」移除本機金鑰與合併基準，保留本機紀錄。之後可再次用金鑰加入。
- 離線可以記錄，但瀏覽器關閉或退到背景後不能保證自動同步。換機前先確認畫面顯示已同步。
- 最近版本僅保留最後 10 次成功寫入，並非每天 10 份，也不是長期備份；還原前先下載本機安全備份，還原會建立新版本並傳到其他裝置。
- 恢復金鑰遺失且沒有已配對裝置時，無法從服務端重設或解密。舊裝置仍可查看自己的金鑰。
- 目前不提供逐台撤銷授權或自動輪換金鑰；若金鑰外洩，先在自己的裝置停止原同步，再建立新空間。持有舊金鑰者仍能讀舊空間。
- 同步服務能看到加密檔案大小、版本、存取時間及處理連線所需的網路資訊；無法讀取訓練明文。限流使用雜湊 IP，不另記錄明文 IP。

## 開發與正式發布

前端維持 GitHub Pages 原網址。同步後端是獨立 Sites 專案，原始碼在 sync-service/，已於 2026-10-27 經使用者同意設為公開並發布。前端由 GitHub Pages 部署；後續發布仍需依 CLAUDE.md 取得使用者確認。

本機操作：
- 主程式：npm run dev（5173）。
- 真實 Worker：在 sync-service/ 執行 npm ci、npm run build，將 drizzle/ 的 migration 套用到 Wrangler 本機 D1，再 npm start -- --port 8788。
- 本機 migration 指令：node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_charming_dust.sql。僅首次建立本機 DB 時執行。
- Playwright 自動啟動 8789 的 SQLite／記憶體 object store 測試服務，使用相同 production handler 與 SQL migration；不接雲端、結束即丟。
- npm run verify、npm run e2e；新增同步 spec 須 --repeat-each 4。
- 真實本機 Worker 整合檢查：node scripts/sync-smoke.mts（須先啟動 8788，不接受遠端網址）。
- 後端型別檢查：在 sync-service/ 執行 npx tsc --noEmit；發布前用 Sites build helper 重新建置。
- production endpoint 綁定加密衍生金鑰；本機測試產生的金鑰不能拿到另一個服務位址還原。勿隨意更換正式 endpoint。

## Android 實機驗收（待人工）

- Chrome 網頁／已加主畫面的 PWA 各建立或加入一次，確認金鑰長按複製、密碼管理工具保存與重新開啟。
- 兩台實機互掃 QR，授權後鏡頭可用，關閉掃描後鏡頭停止；到期及已用的配對碼無法再加入。
- 飛航模式記錄一場，重新開啟網路後確認另一台收到；測試切到背景與鎖定後回到前景。
- 兩台離線各改同一筆，連線後可讀懂衝突內容並選擇；原本待保存數字不因同步而消失。
- 實際掃碼配對使用 App 內掃描，非要求系統相機辨識連結。無 BarcodeDetector 或未授權相機可改貼配對碼。
- LINE 分享仍由本人選收件人；摘要不得出現恢復金鑰或配對碼。
